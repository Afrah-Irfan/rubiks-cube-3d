# 🧊 3D Rubik's Cube Simulator with Shuffle & Layer Rotation

This is a 3D interactive Rubik's Cube built with **Three.js**, featuring:

- ✅ Realistic 3x3x3 Cube
- 🎯 Shuffle button with smooth animations
- 🖱️ Layer-based rotation on click (X, Y, Z axis)
- 🔁 Reset functionality to original state
- ⏱️ Timer and 🧮 move counter included
- ⚡ Performance optimized for browser
